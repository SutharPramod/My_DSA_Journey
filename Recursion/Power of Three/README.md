# LeetCode 326. Power of Three

## Problem Statement
Given an integer `n`, return `true` if it is a power of three. Otherwise, return `false`.

An integer `n` is a power of three, if there exists an integer `x` such that $n = 3^x$.

## Input
An integer `n`.
```cpp

```

## Output
A boolean value (`true` or `false`) indicating whether `n` is a power of three.

## Constraints
* $-2^{31} \le n \le 2^{31} - 1$

## Examples
### Example 1
Input: `n = 27`
Output: `true`
**Explanation:** $27 = 3^3$

### Example 2
Input: `n = 0`
Output: `false`
**Explanation:** There is no power of 3 that equals 0.
