# GeeksforGeeks. While Loop

## Problem Statement
Given a non-negative integer `x`, the task is to print all numbers from `x` down to `0` in decreasing order in a single line, separated by spaces.

## Input
- A single integer `x`.

## Output
- Print integers from `x` down to `0` separated by spaces on a single line.

## Constraints
- `0 <= x <= 100`

## Examples

### Example 1
Input:
3

Output:
3 2 1 0

**Explanation:** The numbers in decreasing order starting from 3 down to 0 are `3 2 1 0`.

### Example 2
Input:
5

Output:
5 4 3 2 1 0

**Explanation:** The numbers in decreasing order starting from 5 down to 0 are `5 4 3 2 1 0`.

### Example 3
Input:
0

Output:
0

**Explanation:** The starting number is 0, so the loop prints `0` and terminates.
