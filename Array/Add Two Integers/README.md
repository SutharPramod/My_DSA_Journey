# LeetCode 2235. Add Two Integers

## Problem Statement
Given two integers `num1` and `num2`, return the sum of the two integers.

## Input
- A single line containing two space-separated integers, `num1` and `num2`.

## Output
- Print a single integer representing the sum of `num1` and `num2`.

## Constraints
- `-100 <= num1, num2 <= 100`

## Examples

### Example 1
Input:
12 5

Output:
17

**Explanation:** `num1` is 12, `num2` is 5, and their sum is $12 + 5 = 17$.

### Example 2
Input:
-10 4

Output:
-6

**Explanation:** `num1` is -10, `num2` is 4, and their sum is $-10 + 4 = -6$.
